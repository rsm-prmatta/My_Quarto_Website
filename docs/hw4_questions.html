MaxDiff (Best-Worst Scaling) forces tradeoffs, producing more reliable preference measurement than traditional ratings.

Important

Key insight: The top and bottom class preferences are very stable across counts, MLE, and Bayesian MNL. The interesting movement is in the middle, where classes are closer together and model uncertainty matters more.

Introduction

MaxDiff, or Best-Worst Scaling, measures preference through tradeoffs. Each respondent sees four MSBA classes and picks the one they like most and least. This is cleaner than ratings because people use rating scales differently, but a best-worst choice forces real separation.

I estimate preferences three ways:

  1. A counts analysis based on percent picked best minus percent picked worst.
  2. A multinomial logit model estimated by maximum likelihood.
  3. The same MNL model estimated with a Bayesian random-walk Metropolis-Hastings sampler.

The goal is simple: see which classes clearly rise to the top, which fall to the bottom, and where the ranking is uncertain.

Counts Analysis

The counts score is the quickest read on preference:

\[ \text{score}_j = \%\text{best}_j - \%\text{worst}_j \]

A higher score means a class wins more often than it loses when shown.

From MaxDiff Data to MNL Choices

Each MaxDiff task becomes two choices: first the best class from all four shown classes, then the worst class from the remaining three. For the best choice:

\[ P(\text{best}=b) = \frac{\exp(\beta_b)} {\exp(\beta_a) + \exp(\beta_b) + \exp(\beta_c) + \exp(\beta_d)} \]

For the worst choice, I remove the best item and flip utility:

\[ P(\text{worst}=c \mid \text{best}=b) = \frac{\exp(-\beta_c)} {\sum_{j \in \text{shown} \setminus b} \exp(-\beta_j)} \]

Because MNL utilities are relative, I set \(\beta_1 = 0\) and estimate \(\beta_2\) through \(\beta_{10}\).

MNL via Maximum Likelihood

The MLE model maximizes this best-plus-worst log-likelihood:

\[ \ell(\boldsymbol{\beta}) = \sum_{\text{tasks}} \left[ \beta_{j_b^*} - \log \sum_{j \in \text{shown}} \exp(\beta_j) - \beta_{j_w^*} - \log \sum_{j \in \text{shown} \setminus \{j_b^*\}} \exp(-\beta_j) \right] \]

The code uses log-sum-exp so the likelihood stays numerically stable.

Show R code 
shown_mat <- do.call(rbind, choice_tasks$shown)
best_vec <- choice_tasks$best_item
worst_vec <- choice_tasks$worst_item
best_pos <- cbind(
  seq_len(nrow(shown_mat)),
  max.col(shown_mat == best_vec, ties.method = "first")
)

log_sum_exp_rows <- function(x) {
  row_max <- apply(x, 1, max)
  row_max + log(rowSums(exp(x - row_max)))
}

ll <- function(beta_free) {
  beta <- c(0, beta_free)

  best_utility <- matrix(beta[shown_mat], nrow = nrow(shown_mat))
  worst_utility <- matrix(-beta[shown_mat], nrow = nrow(shown_mat))
  worst_utility[best_pos] <- -Inf

  best_ll <- beta[best_vec] - log_sum_exp_rows(best_utility)
  worst_ll <- -beta[worst_vec] - log_sum_exp_rows(worst_utility)

  sum(best_ll + worst_ll)
}

Bayesian MNL

The Bayesian model uses the same likelihood plus a weak normal prior:

\[ \boldsymbol{\beta} \sim N(\boldsymbol{0}, 10I) \]

The prior is applied to the nine free coefficients, and I sample from the posterior with a random-walk Metropolis-Hastings algorithm.

Show R code 
log_post <- function(beta_free) {
  ll(beta_free) + sum(dnorm(beta_free, mean = 0, sd = sqrt(10), log = TRUE))
}

mh <- function(beta0, n_iter, step, keep_draws = TRUE) {
  K <- length(beta0)
  draws <- if (keep_draws) matrix(NA_real_, nrow = n_iter, ncol = K) else NULL

  beta <- beta0
  lp <- log_post(beta)
  accept <- 0

  for (t in seq_len(n_iter)) {
    beta_star <- beta + rnorm(K, mean = 0, sd = step)
    lp_star <- log_post(beta_star)

    if (log(runif(1)) < lp_star - lp) {
      beta <- beta_star
      lp <- lp_star
      accept <- accept + 1
    }

    if (keep_draws) {
      draws[t, ] <- beta
    }
  }

  list(draws = draws, accept_rate = accept / n_iter)
}

Counts are fast and transparent. MNL is more rigorous because it models each choice set directly. Bayes adds uncertainty intervals, which are especially useful when middle-ranked classes are close.

Discussion

The clearest takeaway is that MGTA 495 Marketing Analytics (Spring with Yavorsky) is the strongest class in this survey. MGTA 444 Analytics Consulting (Winter with Peterson) is the weakest by the simple counts score and stays near the bottom in the model-based results.

For a quick read, I would use counts. For a cleaner ranking, I would use MLE MNL. For uncertainty and future simulations, I would use Bayesian MNL.

The caveat is that this is still a survey of MSBA students, not a universal ranking of classes. If I extended this, I would segment preferences by student background or career interest.
